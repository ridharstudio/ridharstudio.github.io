# Ridhar Studio

Website profile and landing for Ridhar Studio — software, design, and product.

This repository hosts the GitHub Pages site for the Ridhar Studio profile.

Features included:

- Dark, minimal landing page inspired by jcode.sh
- OpenGraph/Twitter meta tags for better sharing
- Favicon and a simple open-graph image placeholder
- 404 page

To publish: make sure Pages source is set to `main` / `root` in repository Settings → Pages.
